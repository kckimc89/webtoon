나만의 웹툰 창작극장 C3.0 — 첫 시험판

[중요]
- 기존 우리 가족 창작사진관의 ai-lab.html / ai-lab.js는 절대로 덮어쓰지 않습니다.
- 이 시험판은 독립된 새 페이지 index.html 한 파일로 작동합니다.
- 가능하면 기존 웹호스팅에 /webtoon/index.html 같은 새 경로를 만들어 게시한 다음 iPad Safari에서 엽니다.
- 아이패드 파일 앱에서 HTML을 단순 미리보기 하는 방식은 저장/음성 입력 등 브라우저 기능이 제한될 수 있습니다.
- HTML과 백업 JSON은 브라우저/기기별로 보관이 다릅니다. 전시관의 '작품 전체 백업'을 사용하세요.

[첫 5분 사용]
1. 만들기에서 토끼·고양이·요정 등 주인공 선택, 또는 직접 그린 캐릭터 이미지 선택.
2. 비밀 보물/새 친구/신나는 모험 고르기 (아이의 짧은 이야기를 적어도 됩니다).
3. 1/2/4컷 중 선택 후 '내 웹툰 만들기!'
4. 컷을 눌러 사건, 말풍선, 배경, 소품을 수정. '컷 하나 더 이어가기'로 최대 12컷.
5. '전시관에 작품 저장' 후 '작품 전체 백업'을 내려받아 보관.

[AI 협업]
- 본 시험판은 네트워크 없이도 시작 가능한 '웹툰 제작 놀이터'입니다.
- 이야기 초안은 사전에 정한 이야기를 바탕으로 만들어지며, 앱이 스스로 AI를 호출하는 기능은 없습니다.
- 'GPT와 그림 다듬기'를 누르면 현재 컷에 대한 요청문이 복사됩니다.
- ChatGPT를 열고 직접 그린 캐릭터 사진(해당 시)과 요청문을 첨부해 그림을 만든 다음, 결과를 다운로드하여 '이 컷 그림 가져오기'로 가져오세요.
- AI가 캐릭터의 모습까지 완전히 똑같이 유지하는 것은 보장되지 않습니다. 기본 그림/직접 그린 캐릭터 배치는 앱이 그대로 유지합니다.

[저장/안전]
- 별도 IndexedDB: family-webtoon-theater-c30; 기존 사진관 데이터베이스에는 접근하지 않습니다.
- 작품 삭제는 개별 확인 후 실행. '백업 복원'은 기존 작품 전체 삭제 없이 데이터를 추가/갱신합니다.
- Safari의 사이트 데이터 삭제, 사생활 보호 모드, 호스팅 도메인 변경 등으로 로컬 작품이 없어질 수 있어 백업이 중요합니다.
- 개인 얼굴·가족사진 자동 사용, 외부 자동 업로드, 외부 AI API 호출은 없습니다.

[시험 범위]
- 일반 웹 브라우저에서 그림 표시/컷 편집/그림 내보내기/화면 반응을 확인했습니다.
- 실제 iPad Safari의 장기 저장, 파일앱 다운로드/복원, 원본 이미지 촬영은 별도 실사용 검증이 필요합니다.
