마법의 공주 꾸미기 · 독립 실험실 1.0

이번 실험실은 기존 웹툰 창작극장을 덮어쓰지 않습니다.
index.html을 포함하지 않으며 기존 앱을 수정하지 않습니다.

[GitHub 업로드]
1. ZIP 압축을 풉니다.
2. magic-princess-lab.html, 공주 원화 .webp 7개, 보호 마스크 .png 7개를
   기존 webtoon 저장소 index.html과 동일한 위치에 추가합니다.
3. 기존 GitHub 파일을 삭제하거나 교체하지 않습니다.
4. 다음 주소로 접속합니다:
   https://kckimc89.github.io/webtoon/magic-princess-lab.html?v=1

[주요 기능]
- 기존 웹툰 창작극장의 원화 7종 선택
- 마법빛 6종과 두 빛 혼합, 색감 변화 강도 조절
- 꽃잎·별빛·눈꽃·달빛·무지개 장식 효과
- 원본 잠깐 보기/원래대로/PNG 저장
- 별도 실험실 보관함 (기존 웹툰 저장정보와 분리)

[중요한 품질 한계]
- 의상 색변화는 수작업 보호 영역과 색상 구별 기반의 시험 기능입니다.
  레이스·보석·꽃 장식이 독립적으로 변경되는 것은 아닙니다.
- 원본 인물 및 작품은 저장하거나 변경하지 않습니다.
- 작품은 해당 브라우저의 실험실 전용 저장소에 보관하며 기기 간 자동 동기화되지 않습니다.
- 공개 GitHub 저장소이므로 ZIP에는 기존 앱에 원래 사용 중인 공개 공주 그림 자원만 포함되어 있습니다.
